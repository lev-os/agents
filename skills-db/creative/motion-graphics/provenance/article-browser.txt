1: Frame Function, or Why Opus Writes a Program Instead of a Video
Opus 5.5 has no way to output an MP4. Every clip on your feed is a program it wrote, and some other tool turned that program into pictures
The whole trick is one function that answers a single question
python
seek(t) → paint exactly what the screen shows at second t
A headless browser calls it 900 times for a 15-second clip at 60 fps, grabs every frame, and ffmpeg glues them into a file
Nothing runs on a timer, so frame 240 can be drawn on its own without replaying frames 0 to 239. A title that lands too early is one number to change plus a re-render
Left alone, Opus picks the zero-dependency route: one index.html, Playwright capturing frame by frame, ffmpeg encoding. Tommy Rossi found it skips Remotion and HyperFrames even when they're installed, so name a framework if you want one
Where code loses: photoreal scenes, complex characters and organic movement still want footage or a video model. Product films, UI motion, data stories, typography and launch explainers are where seek(t) wins
2: The Rig, or Why the Chat App Alone Gives You Mid Results
The chat app can write the animation. Only an agent with a shell, like Claude Code, can render it, listen to it and look at its own frames
That feedback loop is the whole gap between the viral clips and the "it's a bit mid" replies
python
brew install node ffmpeg python          # apt on Linux
pip install numpy librosa soundfile
mkdir motion-studio && cd motion-studio && npm init -y
npm i -D playwright && npx playwright install chromium
npx skills add remotion-dev/skills       # optional, framework route
npx skills add heygen-com/hyperframes    # optional, framework route
claude --model claude-opus-5-5
Then drop a CLAUDE.md in the project root. Claude Code reads it on every run, so your house rules never need repeating
python
## Render contract
- window.seek(t) paints frame t, nothing else drives the picture
- no CSS transitions, setTimeout or requestAnimationFrame in render mode
- seeded noise only, never Math.random

## Look
- banned: centered title on gradient, everything fading in, corner labels, glow on UI
- one display face, one UI face, one accent
- something new on screen every 2 to 4 seconds

## Sound
- score and SFX synthesized in code unless a track is supplied, -14 LUFS

## Before you show me anything
- render one frame per beat as a contact sheet, score it, fix the worst 3
Effort settings: Opus 5.5 starts on medium. Every viral one-shot ran on xhigh or max. Medium is for small fixes, xhigh for new films, max when the first 3 seconds have to carry a launch
3: The Brief, or Why a Vibe Prompt Leaves Every Decision Open
Ask for "an insane product video" and the model fills each blank with the safest default it knows. That's where the centered gradient title comes from
The famous one-liner still has a job
python
make a dynamic 15-second motion graphics video that shows what an incredible motion designer you are, like it's your showreel for a résumé. go all out.
"Showreel" hands Opus a genre with known rules. Making the model the subject means there's no product to get wrong. 15 seconds fits 6 to 8 shots, and "go all out" stacks extra effort on top of xhigh
Run it once to test your rig and move on. Hundreds of people sent the same sentence and got reels that rhyme with each other, a pattern the athemeroy dataset labels brief contagion
When there's something to sell, Opus needs a production document before any render task. Thariq from the Claude Code team put it bluntly: the post says one-shot while the prompt runs 10k characters with skills, examples and keys
python
FILM      one sentence the viewer keeps, audience, duration, formats
ASSETS    real logo, real UI screenshots, brand type and colors, audio
VISUAL    what to keep from the reference, which clichés to avoid
HARD LINE never invent product screens or metrics
DELIVER   storyboard, contact sheet, final video, poster frame, source
Tony Dinh's TypingMind reel: three extra lines did it, the product URL, a demand for real screenshots, logo and assets, and "must have music". Opus went to the site, collected everything itself and finished in under 30 minutes. A year earlier a similar launch video cost him about $1,200
Rob Hallam's follow-up: after his first reel he asked for a product ad in the same chat, and it came out faster because the renderer, audio synth and export pipeline already existed. Keep one session per brand
Keys: put them in .env and refer to them by name in the prompt. achxvi's public Pocketsflow prompt used a joke placeholder for exactly this reason
4: The Reference, or Why Every One-Prompt Reel Looks the Same
With no visual grammar supplied, Opus brings its own, and unrelated reels start looking like siblings
Rexan Wong went through dozens of viral clips and kept seeing the same thing: naming a style works better than describing one, and a reference frame or video hands over pacing, type and transitions in one go
Three kinds of reference pull their weight. A single frame of a video you love, a short clip Opus slices with ffmpeg, or a folder of your own past work. Pleometric's TikTok-feed piece grew from one frame of another viral animation, and his Donald-style film pointed at his own PC-98 gallery, a library nobody else can copy
python
Reference: ./refs/launch.mp4
1. Extract a frame every 0.5s with ffmpeg and study them
2. Write docs/style_guide.md: palette in hex, type, shot lengths, transitions, camera, grain
3. Write docs/shotlist.md for a [DURATION]s video about [SUBJECT] in that style
4. Take the grammar, never the subjects, logos or copy
5. Show me both files and wait for my OK before any code
For a product film, also let Opus pull the real screens from the live site and review that asset list yourself. If something is missing, the agent should stop and ask instead of drawing a convincing fake
Library choice: Pleometric suggested p5.js and Opus wrote its own paper renderer instead. Spell out the look and the limits and let the model pick the technique
Where to dig for references: whatships.com for launch videos, Dribbble motion, your competitors' launch films
5: State Lists, or Why One Shape That Never Cuts Beats Ten Effects
"Zoom in, morph, add particles" is a list of activity. A storyboard says what the viewer knows at each second
python
00-02s  HOOK     one image that earns attention
02-05s  PROBLEM  the friction, shown on screen
05-09s  REVEAL   the product enters through a real interaction
09-13s  PROOF    one screen or number backs the claim
13-16s  CLOSE    a clean final state and a readable CTA
The most-bookmarked prompt of launch week was an XML spec. @twoclipping's UI morph pulled 907K views and 19K bookmarks with it, and @verbove's MakerMap film used the same structure on a real product
The idea behind both: a single container morphs size, radius and color from state to state, a cursor drives every change with real clicks, and the final frame matches the first so the clip loops
python
logo → CTA button → email field (typed) → loader → success check → dashboard → chart draws itself → tooltip → ⌘K palette → toast → logo
Each beat needs an entry state, an exit state and a reason to be there. If the agent can't explain why shot four exists, shot four gets cut
The story version: NFT_Chen had Opus code a cartoon video editor with a timeline, waveform and export button, then stage the whole film inside it. A fake UI works like a film set where every element has a known state
6: Springs and Sound, or Why Cheap Motion Feels Cheap
A fixed easing curve slides from A to B. Motion with mass speeds up, overshoots a hair and settles
Closed-form springs give that feel while staying a pure function of time, so seek(t) stays deterministic. When a value changes target several times, like a cursor or a container's width, stack one spring per change instead of restarting it
python
track(t) = v0 + Σ (v_i − v_(i−1)) × spring(t − t_i)
That way frame 812 still renders without simulating frames 0 to 811
Give each class of object its own rule. Small UI snaps with minimal overshoot, panels settle, the camera glides almost invisibly, headlines land hard and hold long enough to read, mascots bounce on purpose. If everything overshoots, nothing feels precise
Sound runs on the same clock as the picture. Rob Hallam assumed the audio in his reel was added in post, and it came straight from code. @oozn's Steve Jobs biopic synthesized its soundtrack in Node with 23 transitions locked to 120 BPM
With your own track, measure it before you animate
python
python beats.py song.wav > beats.json   # librosa: bpm, beats, downbeats, hits
State changes go on beats, big moments on downbeats, clicks and whooshes on hits
The blindfold test: close your eyes and listen to the film. If the audio has no shape without the picture, the sound design is unfinished
7: The Critic, or Why Opus Has to Watch Its Own Frames
Opus 5.5 reads images, so it can inspect what it just rendered. That one habit is what the clips that blew up had in common
@mablesjoseph was open about his watercolor short: 163 model calls and close to 7 hours of work. Drew's launch-day piece reached 1.7M views and still showed visible cleanup rounds
Skip watching a full export ten times in a row. Have ffmpeg build the evidence
python
contact sheet   2 frames per second, 6 across
strip           12 consecutive frames around the fastest move
phone test      frames scaled to 360 px wide
loop check      the clip played twice back to back
determinism     render frame 300 twice, the hashes must match
Then hand Opus a critique task with teeth
python
Judge only the rendered frames, ignore what you meant to make
Score 1-10: hook in 2s, phone readability, motion, variety, sound sync, brand accuracy
List the 3 worst defects with timestamp, evidence and a local fix
Patch those seconds, re-render them, repeat until every score is 8+
What to hunt for: overlapping text, elements sliding where they should ease, corner labels, blurry scaled type, a dead beat with nothing happening, a stutter at the loop point
8: The Skill, or Why the Next Video Should Be One Sentence
If the only record of the film lives in a chat, you had a lucky session. Keep the decisions in files the next run can read
python
motion-studio/
  brief.md         goal and product facts
  style_guide.md   palette, type, motion, banned defaults
  shotlist.md      beats, states, timestamps, purpose
  assets/          approved logos, screens, sound
  src/             seekable composition and motion code
  reviews/         contact sheets and defect notes
  out/             one export per format
Overnight runs need gates. Donald dictated for five minutes, went to sleep and woke up to a 142-second music video that went on to 2.1M views. His prompt ran around 9,500 characters, and @pradeepXkapoor's "Pip" robot film used a 19,000-character brief
python
GATE 1  references and product assets approved
GATE 2  style guide and shot list approved
GATE 3  stills for every shot, critiqued
GATE 4  animatic at 960x540 with placeholder audio
GATE 5  full pass, polish, sound
GATE 6  formats, loop check, poster frame, README
The agent can work for hours between gates. A missing interface screenshot is a blocker, and an unclear reference gets a question or one test frame before 900 polished wrong ones
Generate-then-trace: Donald's key move. Seedance 2.5 renders base shots with characters and physics, then Opus redraws the whole film in JavaScript on top, so viewers only see the code-drawn layer. John Heibel's PDoom repo (1.1K stars) shows the subagent version, where Opus writes ANIMATION_GUIDE.md to brief parallel workers across nine chapters
Formats: every aspect ratio comes from the same timeline, never from a crop. Vertical gets bigger type and fewer elements, square gets tighter holds, wide gets more spatial context
Wrap all of this into a skill and the course shrinks to one line
python
/motion-reel for [URL], 20s, vertical, reference ./refs/frame.png
Turning it into income: achxvi now sells exactly this as a service, with music, a mascot in any style, product features, an offer at the end, any language and up to 3 edits. His 38-second vertical product film took 45 minutes
