Steps
1. Run `date -u +%Y%m%dT%H%MZ`. That is STAMP. Make the folder S/pass-STAMP.
2. List the chats with a program, not with a T3 tool:
   `node K/list-chats.mjs --projects S/projects-20261118T2035Z.json --out S/threads-STAMP.json`
   It uses the t3 command line and prints the count. When it exits 1, stop: reply "tick skipped:" and its last
   line. Never read the list into your context; use jq for a count.
3. Scan: `node K/sweep.mjs scan --threads S/threads-STAMP.json --projects S/projects-20261118T2035Z.json --self OWNER --text`
   Keep its first line (the counts).
4. Count the chats to read: `grep -c "" S/to-read.jsonl` (0 when the file is empty or missing). When it is 0, load
   no T3 tool and read no chat: go to step 5. When it is over 0, load the read tool with ToolSearch, query
   `select:mcp__t3-code__t3_thread_read`, then:
   `node K/sweep.mjs brief --out S/pass-STAMP/labels.jsonl > S/pass-STAMP/label-brief.txt`
   Read S/pass-STAMP/label-brief.txt in full and do what it says yourself: it is the order for the label reader, and
   you are that reader. Then `node K/sweep.mjs merge --labels S/pass-STAMP/labels.jsonl`.
5. Queue: `node K/sweep.mjs queue --thread OWNER --title "CEO > global"`
6. Cards: `node K/cards.mjs brief --thread OWNER --out S/pass-STAMP/cards.jsonl > S/pass-STAMP/card-brief.txt`
   When the brief names at least one chat, read it in full and do what it says yourself: you are the card reader.
   Write each card for a reader who has never seen the chat: plain words, no code name, no file name, no id without
   its meaning in the same sentence. Then `node K/cards.mjs merge --thread OWNER --cards S/pass-STAMP/cards.jsonl`.
7. Write S/index-status.json with the Write tool, one JSON object:
   {"at": "<date -u +%Y-%m-%dT%H:%MZ>", "stamp": "STAMP", "chats": <count in the list>, "read": <chats you labeled>,
    "cards_written": <cards you wrote>, "scan_line": "<the first line of step 3>", "problems": ["<each command that
    failed, with its last line>"]}
8. Reply with one line: the time, the counts of step 7, and each problem. Nothing else.
