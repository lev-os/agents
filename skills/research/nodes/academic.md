# Academic

1. Convert the question into field terms, methods, date range, and inclusion criteria.
2. Run `lev research <query> -s academic --no-wikify`; provider order is fixed by runtime metadata.
3. Resolve DOI/arXiv identifiers and deduplicate papers.
4. Expand references and cited-by evidence only when the question requires a literature review.
5. Retrieve full text for decisive papers, then synthesize consensus, disagreement, limitations, and citations. Stop.
