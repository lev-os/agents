2026-09-27 · workstream task-bundle-ontology · capture .lev/pm/workstreams/task-bundle-ontology/captures/20260927-capture-sweep.yaml

9 spikes (5 live lev runs), Astra and Fable on the core loop, Fable on sequence. 15 questions, each with a default, in dependency order. The three-face sample is first.

WHAT WE LEARNED TONIGHT

Live runs and spikes, in one screen

  • Fail-open gate fixed (uncommitted): FlowMind's executor and core/eval no longer pick a branch by position when a gate has no verdict; the node fails. Typecheck x2 exit 0; 16/16, 37/37, 48/48 on the named test files. DNA gate_evaluator_default: 1 known violation, now 0.
  • The live lev exec path uses a different gate (core/exec/src/execution/dispatch/gate.ts) that already fails closed on a missing variable.
  • The happy path is broken 4 ways:
  1. --knob task= is read as a task-packet id, and the positional prompt is silently replaced by the flow's default.
  2. A fresh folder stops at Claude Code's "trust this folder" screen.
  3. Print mode needs a turn cap nobody sets.
  4. --until hangs after the agent says DONE, so its verifier, timeout and receipt never happen.
  • The default check does not check the work: intent_conservation compares the delivered prompt with the declared one and ignores the agent's output. 721 of 735 task slices already declare a verifier command.
  • Warm workers warm nothing: the pool flips a status flag, reuse_node is a no-op, and every step's session is shut down.
  • DNA:
  • 176 files, 39,683 lines; about 15% are constraints with a runnable check. The last ratchet run: 328 pass, 24 fail, 155 skipped, and it is not in CI.
  • 31% of the lines are vendored research that says nothing reads it.
  • "14/15 vs 0/15" is one run per arm, scored on a rubric.
  • Skills rarely validate what they write: 1 of 13 repo writers, 1 of 21 global writers. The lifecycle skills and pm templates live only in the personal agents repo.
