NEW README

Snippet-first root README

Six sections, ~60 lines. The paste block is the product; everything else frames it.

1. Title + one line. "Agent-agnostic CLI for AI-assisted development. It installs a shared set of SDLC skills onto your machine so your coding agent runs the same plan → execute → review workflow everyone else does." No mission statement.

2. Set up — the copy-paste block (below), introduced by a single line: Paste this into Claude Code, Codex, Cursor, or whatever agent you use. Followed by three requirement lines (git, Node 20+, npm on PATH; Bitbucket SSH; ULTA_HOME=<path> to install elsewhere) and one pointer: if either command fails, the error names a section in docs/installation.md.

3. Daily use — literal prompts, since that is what the user types: "Use jira-ingest on ULTA-1234", "Use planning to turn that into an implementation plan", "Use execute", "Use review". Plus ulta skill list --global for the full set — a real command (surface-registry.js:486-502) that replaces the dead lifecycle cross-reference.

4. Where things land — four rows, no prose: .ulta/user/ (git-ignored), ~/.config/ulta/config.yaml, ~/.agents/skills/, ~/.local/share/ulta-ai-cli.

5. Update — corrected, not copied forward: ulta update is the path. Re-running install.sh from inside the clone does not pull new commits (verified: install.sh:19-23 sets the in-place flag and :126-136 returns before any fetch). ulta update --bulletin shows what changed; --verify checks it applied.

6. More — five one-line links: ulta --help, installation, skills, config spec, AGENTS.md.

Dropped: the 54-line mermaid diagram, rollout model, Context Engine relationship, the hand-maintained command reference (ulta --help is generated and cannot go stale), capability and limitation decks, audience routing.
